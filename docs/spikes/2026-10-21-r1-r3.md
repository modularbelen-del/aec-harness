# Spike R1–R3 (2026-10-21, Claude Code 2.1.306, Windows 10, uv 0.13)

Throwaway plugin in a folder named `spike Çınar` (space + Turkish characters), installed through a local
marketplace into an isolated `CLAUDE_CONFIG_DIR` (also with a space and Turkish characters).

| Risk | Result | Evidence |
|---|---|---|
| R1: `${CLAUDE_PLUGIN_ROOT}` in `.mcp.json` args, `${user_config.*}` in `env`, `uv` on PATH | PASS | probe saw `argv[2] = <SCRATCH>/spike Çınar/plugin/probe.py` (forward slashes) and `AEC_REVIT_PORT_DEFAULT=48884`; `claude mcp list`: `plugin:spike:probe ... ✔ Connected` |
| R2: session env reaches the plugin MCP process | PASS | started with `REVIT_PORT=48885`; probe saw `REVIT_PORT=48885` |
| R3: plugin MCP tool name | PASS | `mcp__plugin_spike_probe__ping` → pattern `mcp__plugin_<plugin>_<server>__<tool>`; for us `mcp__plugin_aec_revit__<tool>` |
| Hook command on Windows | PASS | `uv run --no-project --python 3.12 python "${CLAUDE_PLUGIN_ROOT}/hooks/hook.py"` printed `SPIKE-HOOK-OK <path with space and Ç>` into the session context |

Other findings:
- A userConfig option with a `default` is applied even when the user never set it; install prints
  "1 userConfig option not yet set" and accepts `claude plugin install ... --config KEY=VALUE`.
- `CLAUDE_PLUGIN_DATA` = `<config dir>/plugins/data/<plugin>-<marketplace>`; the MCP process also gets
  `CLAUDE_PROJECT_DIR` (= session cwd).
- A local-directory marketplace is loaded in place (`Read from: <source dir>`), not copied to the cache;
  a GitHub marketplace uses the versioned cache path. Paths in skills must never assume either.
- `claude plugin validate` passes without `version`; it only warns. The directory-submission profile wants
  README.md and a LICENSE (repo root counts). Not needed for our own marketplace.

Chosen forms:
- `.mcp.json` (Plan 1C): `{"command":"uv","args":["run","--quiet","--with","mcp[cli]>=1.9,<2","mcp","run","${CLAUDE_PLUGIN_ROOT}/mcp/revit_client/main.py"],"env":{"AEC_REVIT_PORT_DEFAULT":"${user_config.revit_port}"}}`; client uses `REVIT_PORT` if set, else `AEC_REVIT_PORT_DEFAULT`. No second server needed.
- `hooks.json` (Task 6): the command above with `hooks/session_start.py`.
